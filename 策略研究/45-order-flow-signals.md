# 45 — 订单流信号构造方案（换数据源，找比 K 线更高一层的 alpha）

> 背景：research/30~43 已坐实「币圈永续 K 线（4H+15m）公开数据 + 零售成本，没有容易的普适 alpha」。
> 结论指向「下一维度该换数据源」。本方案定义**用订单流数据（taker 流 + 订单簿）构造信号**的完整思路，
> 供数据到位后直接照着写验证脚本。
>
> 铁律：每一步数据 + 公式支撑，不拍脑袋。所有参数标注「来源 + 如何用数据定」，凡未验证的一律标「未验证」。

---

## 一句话结论

K 线只有「开高低收」聚合信息；**taker 流（逐笔成交）多一个「方向」维度**——谁在主动买、谁在主动卖、
下了多少。本方案定义 5 个订单流信号，每个都有明确公式和金融逻辑，但**是否在 SOL 永续上有 alpha，
必须用 VBT 的 CPCV/Monte Carlo 验证，一个都还没验证。**

## 二、五个信号构造

> 参数统一标注 `[待定]` = 数据下来后网格 + Monte Carlo 选，不是拍脑袋；`[数据定]` = 用数据分布直接算。

### 信号 1：累计成交量差 CVD（最核心）

```
对每笔成交：delta_i = (side_i == buy) ? +size_i : -size_i
CVD(t) = Σ_{i≤t} delta_i            # 一路累加（积分）
```

- **是什么**：一条「资金流向」曲线，主动买多往上爬、主动卖多往下掉。
- **凭什么可能有用**：CVD 变化**领先价格**——价格还没动，CVD 先掉头（买盘/卖盘动能先衰竭）。
- **参数**：无（纯累加）。可选平滑窗口 `[待定]`。
- **状态**：未验证。

### 信号 2：买卖失衡比（短窗口）

```
imbalance(t) = (Σ buy_size − Σ sell_size) / (Σ buy_size + Σ sell_size)   # 窗口 [t−w, t]
```

- 范围 −1 ~ +1；+1 = 窗口内全是主动买，−1 = 全是主动卖。
- **凭什么可能有用**：短窗口失衡打到极端（全在抢买/全在抛），往往是冲过头、要回踩。
- **参数**：窗口 w `[待定]`（候选 1m/5m/15m，网格定）。
- **状态**：未验证。

### 信号 3：大单净流（聪明钱）

```
large_delta_i = (side_i == buy 且 size_i ≥ Q) ? +size_i
              : (side_i == sell 且 size_i ≥ Q) ? −size_i
              : 0
large_CVD(t) = Σ large_delta_i
Q = 过去 N 天单笔 size 的 P90 分位      # [数据定]，分位档位本身 [待定]
```

- **凭什么可能有用**：一笔 87 SOL 的大单比一百笔 0.01 SOL 散户单更有信息量，大单≈大资金/机构。
- **参数**：分位档位 P（90 vs 95）`[待定]`、回看 N `[待定]`。
- **状态**：未验证。

### 信号 4：订单簿失衡（需 L2 深度数据）

```
imbalance(t) = (Σ_{前k档} bid_size − Σ_{前k档} ask_size) / (Σ bid_size + Σ ask_size)
```

- **是什么**：直接看「买墙厚还是卖墙厚」。
- **凭什么可能有用**：墙厚的一侧短期有支撑/压力。
- **参数**：档数 k `[待定]`（前 5 / 10 / 20 档）、采样频率 `[待定]`。
- **状态**：未验证（依赖订单簿数据，第二批拉）。

### 信号 5：CVD-价格背离（最强候选）

```
顶背离（偏空）：price 创 N 根新高，但 CVD 未创新高
底背离（偏多）：price 创 N 根新低，但 CVD 未创新低
```

- **凭什么可能有用**：经典反转信号；用 CVD 替代传统成交量，多一个「方向」维度，
  能区分「真突破（量价齐动）」和「假突破（价动量不动）」。
- **参数**：背离回看窗口 N `[待定]`（候选 20/50 根）。
- **状态**：未验证。

## 三、数据预处理

逐笔成交一天几十万笔，量太大，先聚合再喂 VBT：

1. 逐笔 → **分钟级 bar**（聚合窗口：CVD 用累加、失衡比用窗口求和）。
2. 对齐到 SOL 4H K 线的同一时间轴（与已验证的 SOL 策略同口径，便于对比/组合）。
3. 产出结构：`{时间, close, CVD, imbalance, large_CVD, buy_ratio}` 宽表，喂 `vbt.Portfolio.from_signals`。

---

## 四、验证方案（沿用 research/30~43 的尺子，不降低标准）

1. **样本**：SOL 逐笔成交 5 年（2021.9 起，含 2022 熊市），与 K 线策略同一时间轴。
2. **回测**：信号 → 布尔 entry/exit → `vbt.Portfolio.from_signals`，fees=0.05%（taker 档），双向。
3. **判定尺子（CPCV / Monte Carlo，250 路径 × 5 种子）**：
   - MC 中位数为正 + 正收益占比 >50% + 选参跑赢随机参 + 5/5 种子稳定 → 才算 edge。
4. **对照**：新信号必须**跑赢** research/40 的 SOL 基线（protected MC 中位 +19.49%），
   或提供「正交于 K 线」的增量（如与 SMA 策略组合后 MC 提升），否则无价值。
5. **诚实标注**：若订单流信号全不通过，如实记录「订单流维度在 SOL 上也无普适 alpha」，
   继续换下一个数据源（链上）。

## 五、执行顺序

1. 等数据拉下来 → 验信号 1（CVD）+ 信号 5（背离）——信息量最大、最可能跟价格不同源。
2. 信号 2/3 补充；订单簿信号 4 等第二批数据。
3. 每个信号单独过 CPCV/Monte Carlo，通过才进入组合。
