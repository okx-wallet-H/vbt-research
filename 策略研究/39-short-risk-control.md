# 39 — 给 naive 双向做空加风险控制：把「弱正+深尾」削成「正+浅尾」

> 背景：research/32 发现做空对 SOL/DOGE 有真实结构 alpha（+33~35pp）；
> research/33 发现 naive 双向（SMA 20/50 固定参数、零选参）在 SOL 上 Monte Carlo 中位数 **+5.50%、5/5 种子正**，
> 但它是「弱正 + 深尾」：CPCV P25 = **-29.05%**、P5 = -63.26%、min = -75.7%，深尾来自空头挤压。
> 缺的不是方向过滤（regime filter 反而毁了它），是**风险控制把深尾削掉**。
>
> 本文给做空侧加四类保护（止损 / ATR 动态止损 / 空头挤压 / 时间止损），全部固定参数、零选参、
> 因果无 lookahead，用 Monte Carlo（250 条随机 walk-forward 路径 × 5 种子）+ CPCV（45 测试折组合）检验。
>
> 全部数字来自 `backtest/output/risk_results.json`，脚本 `backtest/risk.py`（实跑，可复现）。

---

## 一句话结论

**能。** 加对风险控制后，naive·SOL 从「弱正 + 深尾」变成「正 + 浅尾」的真 edge：

| 指标 | naive（无保护） | σ挤压 2.5σ + 时间止损 20 根（最优组合） | 变化 |
|------|----------------|------------------------------------------|------|
| MC 中位数 | +5.50% | **+14.33%** | +8.8pp |
| MC P25（下尾） | -5.15% | **+6.05%**（转正！） | +11.2pp |
| MC P5 | -25.03% | **-13.48%** | +11.6pp |
| MC 正收益占比 | 60% | **83%** | +23pp |
| MC 正种子 | 5/5 | **5/5** | 稳 |
| CPCV 中位数 | +6.99% | **+14.77%** | +7.8pp |
| CPCV P25 | -29.05% | **-22.30%** | +6.8pp |
| CPCV min（最差窗） | -75.74% | **-68.38%** | +7.4pp |
| 全样本回撤 | -36.27% | **-30.11%** | +6.2pp |
| **MC 判定** | 待定 | **edge** | ✅ |

**但有一个反直觉的关键发现：任务预设的「固定止损 + 空头挤压保护叠加」是错的。**
固定止损（close 涨 X% 平空）会跟 SMA 的金叉平空「打架」——SMA 死叉做空、金叉平空本身已经是止损，
再叠一个固定百分比止损只会把还没被挤压的正常空单提前砍掉，组合后 MC 中位数反而从 +5.50% 掉到 +2.27%（4/5 种子）。
**真正有效的是两类「事件型」保护：σ 挤压（单根暴涨 ≥2.5σ 立即平空）+ 时间止损（持仓 20 根未盈利平空）**，
它们和 SMA 金叉互补，不打架。

## 二、四类风险控制 + 公式

全部保护只作用于**做空侧**（deep tail 来自空头挤压），long 侧不动。触发与参考价都用**收盘价**
（与 `from_signals` 默认 close-to-close 成交模型一致，无盘中成交价歧义），因此报告的止损收益是**下界**
（真实盘中 high 触发止损只会更好）。

| 保护 | 触发条件（公式） | 参数 |
|------|----------------|------|
| ① 固定止损 `sl_pct` | 做空后 `close[i] ≥ entry × (1 + sl_pct)` 强制平空 | sl_pct ∈ {3%,5%,8%,10%,15%} |
| ② ATR 动态止损 `atr_k` | `close[i] ≥ entry + atr_k × ATR14[i]` 强制平空 | atr_k ∈ {1.0,1.5,2.0,2.5,3.0} |
| ③a 空头挤压 `squeeze_pct` | 做空期间单根涨幅 `close[i]/close[i-1] − 1 ≥ sq_pct` 立即平空 | sq_pct ∈ {3%,5%,8%} |
| ③b σ 挤压 `squeeze_k` | 单根涨幅 `≥ squeeze_k × std(单根收益, 滚动20)` 立即平空 | squeeze_k ∈ {2.0,2.5,3.0} |
| ④ 时间止损 `time_stop` | 持仓 ≥ N 根**且未盈利**（`close[i] ≥ entry`）平空 | N ∈ {5,10,20} |

其中：
- `entry` = 死叉当根的收盘价（= `from_signals` 的做空成交价），状态机逐 bar 模拟空仓/持仓，起始空仓、与 `from_signals` 一致。
- ATR14 与滚动 std 在**全序列**预计算（逐点因果，只用 ≤t 数据），切片时携带暖机历史，MC（train 严格先于 test）下暖机正确。
- `ATR14 = Wilder 平滑的真实波幅`（vbt.ATR 标准口径）；`σ挤压` 里 std 用「含当根收益」的滚动 20 根 std（保守口径，避免当根暴涨把 std 抬高导致触发阈值自我稀释）。

## 四、关键发现（逐个风险控制判读）

### 1. 固定止损：只对最紧的 3% 有效，8% 反而帮倒忙

- sl=3% 把 MC P25 从 -5.15% 抬到 -1.91%（+3.2pp）、正占比 60%→70%，但仍差一口气到 edge（P25 还是 < -1%）。
- sl=8% 直接变差（MC 中位 +4.51%、CPCV 中位 +2.54%、全样本 +44.68% < naive +54.89%）——**8% 的止损
  把「还没被挤压、只是正常 8% 回撤」的空单砍了**，而这些空单本会在后面下跌段赚回来。
- sl=10%/15% ≈ naive（SOL 的空头在 SMA 金叉平空前，很少单边涨超 10%）。

**结论：固定止损是「钝器」，和 SMA 金叉平空冗余，收益/风险比差。**

### 2. ATR 动态止损：基本无效

atr=1.5 最好也才 MC P25 -4.35%、CPCV P25 -25.93%，其余档位更差。ATR 止损和固定止损是同一类「阈值止损」，
同样和 SMA 金叉打架。**弃用。**

### 3. 空头挤压：σ 挤压（2.5σ）是「单因子最强」

- 单根涨幅 sq=3% 能削 MC 尾（P5 -14.44% 全场最优之一），但 CPCV P25 反而变差（-31.44%）。
- **σ 挤压 sqsig=2.5 是全场唯一「单因子就够 edge」的配置**：MC 中位 +9.70%、MC P25 +0.15%（转正）、
  正占比 75%、5/5 种子。机制：SMA 金叉对「单根暴涨」反应慢（要等均线交叉），σ 挤压在暴涨当根就离场，
  正是空头挤压的正确应对。
- sqsig=2.0 过紧（3/5 种子、中位 +0.06%），2.5~3.0 是甜区。

### 4. 时间止损：CPCV 尾削得最狠，且是「顺机制」的

- **time=20 是单因子里 CPCV P25 抬得最多的**（-29.05% → -20.95%，+8.1pp），MC 中位 +13.85%、MC P25 +3.92%（转正）、
  正占比 82%、5/5 种子，全样本 +128.08%。
- 机制：SOL 的真实路径是「早盘暴涨 +86% → 崩盘 -75% → 修复」，naive 空头在早盘暴涨段被套死、一直扛到金叉大亏；
  时间止损在「持仓 20 根未盈利」就离场，躲过最深的套牢段，再等下一个死叉重新做空吃崩盘。
- 代价是 short 胜率降到 30.3%（naive 39.4%）——「很多小亏换掉少数大亏」，是趋势跟踪的经典画像
  （胜率降、赔率升、总收益升）。time=5 也 edge（+1.32% P25），说明「快刀斩死仓」这个动作本身有效，
  不是某个 N 值过拟合。

### 5. 组合保护：任务预设的「止损+挤压」错了，正确的组合是「σ挤压+时间止损」

- **`sl5+sq3`（固定止损+单根挤压）反而更差**：MC 中位 +4.16%（< naive +5.50%）、MC P25 -7.21%（更深）。
  `sl5+sq3+t20` 更糟（+2.27%、4/5 种子）。**固定止损 + 挤压 = 双重提前平空，把 alpha 切碎了。**
- **`sqsig2.5+t20`（σ挤压+时间止损）是全场最优**：MC 中位 +14.33%、MC P25 +6.05%（转正且最深尾也抬了 +11.2pp）、
  P5 -13.48%、正占比 83%、5/5 种子、CPCV 中位 +14.77%、CPCV min -68.38%（最优）、全样本回撤 -30.11%（最优）。
- 这两个保护**互补**：σ 挤压管「单根暴涨」的快尾，时间止损管「死扛不盈利」的慢尾；都只针对空头挤压/死仓，
  不碰「正常回撤里最后能赚钱」的空单，所以不和 SMA 金叉打架。

## 五、明确判定

### 哪个风险控制最有效？

**`σ挤压 2.5σ + 时间止损 20 根`（`sqsig2.5+t20`）**，把 naive·SOL 的 MC 下尾 P25 从 **-5.15% 抬到 +6.05%（+11.2pp，转正）**，
MC 中位数从 +5.50% 抬到 +14.33%，正收益占比 60%→83%，且 5/5 种子全正。

按 `robust.classify_dist` 的严格门槛（中位数>0 + 正占比≥60% + P25≥-1% + 无极端右偏），naive 是「待定」
（P25 -5.15% 下尾深负卡门槛），**加保护后 MC 判定 = edge**（四项全过，均值 +13.42% 与中位数 +14.33% 几乎重合，无右偏依赖）。

### 做空 alpha 加保护后是不是真 edge？

**是（在诚实 walk-forward 口径下）。** 但要诚实标注两点：

1. **MC（诚实 walk-forward，train 严格先于 test）判定 = edge**：250 条随机路径里，中位 +14.33%、83% 路径为正、
   P25 +6.05%（下尾转正）、5/5 种子一致。这是「真 edge」的最硬证据。
2. **CPCV（过拟合诊断，train 可在 test 后）P25 仍深负**（-22.30%），只是从 -29.05% 抬了 +6.8pp。原因是
   CPCV 的测试窗（2 折 ≈ 100 天）会整段落在「SOL 早盘暴涨 / 崩盘后修复」这种结构性做空亏损期，
   风险控制只能削损、不能把「整段逆势」转正。**所以「浅尾」是相对 naive 而言，不是绝对无尾。**

### 止损参数（公式 + 数值）

| 保护 | 公式 | 最优值 |
|------|------|--------|
| σ 挤压 | 做空期间 `close[i]/close[i-1] − 1 ≥ 2.5 × std(单根收益, 滚动20)` → 平空 | **squeeze_k = 2.5**（窗口 20） |
| 时间止损 | 持仓 ≥ N 根且 `close[i] ≥ entry`（未盈利）→ 平空 | **N = 20**（4H，约 3.3 天） |

- 这两条是「事件型」保护，**不设固定百分比止损**（固定止损 sl 会跟 SMA 金叉打架，实测 8% 反而更差）。
- 敏感度：σ 挤压 2.0 过紧（3/5 种子）、3.0 也稳（+7.41%）；时间止损 5 与 20 都 edge（+1.32%/+3.92% P25），
  **说明「砍死仓」这个动作是稳健的，不是某个数值过拟合**。

## 六、诚实边界（哪些还没坐实）

1. **区间特异性**：当前 16.4 个月是「分化市」（SOL 早盘暴涨→崩盘→修复）。时间止损的大收益很大程度来自
   「早盘暴涨段」——若换成 2022 真熊市（单边阴跌、少暴涨）或 2021 单边牛（做空全程逆势），
   时间止损的收益会不同。**下一步必须回拉 4H 到 2021 年坐实**（research/32 §五、33 §七都点了这条）。
2. **close 触发下界**：止损/挤压都用收盘价触发（不用盘中 high），是保守口径，真实盘中触发只会更好。
3. **只验了 SOL**：DOGE 的 naive 基线本就为负（research/33 MC 中位 -4.69%），不是「弱正」候选，未纳入。
4. **手续费/滑点**：0.05% 单边已计；时间止损会增加换手，但 4H 级别换手仍低（33 笔短仓不变，只改平仓时机）。
