# 42 — 15m 微观结构信号：成交量异动 / 量价背离 / 放量突破，有没有 4H 没有的 alpha

> 背景：research/30~36 证明 4H 纯价格指标（RSI/SMA/SuperTrend）与量能因子全是过拟合
> （MC 中位数 -6%~-16%、正收益占比 20~42%）。但微观结构（成交量、量价关系）是 4H 低频里
> 被抹掉的信息，15m 上可能还有。本任务验证四个微观结构信号在 15m 上的 alpha：放量突破、
> 量价背离、成交量异动、量能确认，严格走 Monte Carlo（诚实 walk-forward）+ CPCV + 参数扰动。
>
> 全部数字来自 `backtest/output/m15_microstructure_results.json`，脚本 `research_42_m15_microstructure.py`
> （实跑 2508.9s，可复现），数据 `backtest/output/okx_15m.pkl`（OKX 15m 真实 K 线，含 Volume）。

---

## 一句话结论

**15m 的微观结构信号没有 4H 没有的 alpha。四个信号（放量突破 / 量价背离 / 成交量异动 / 量能确认）
在 3.7 年真实 OKX 15m 数据（BTC/ETH/SOL）上，Monte Carlo 中位数全部 ≤0、正收益占比全部 ≤50%、
12 个「策略×币」组合无一通过「edge」检验（全部 luck）。不但没找到新 alpha，反而比 4H 更糟：**
「追量做多」类信号（放量突破/成交量异动）在 15m 上是**系统性负期望**（MC 中位数 -13%~-37%），
因为 15m 的量能尖峰在币圈是**局部见顶/衰竭**信号，不是动量延续。唯一贴近零的是「量能确认」
（SMA 金叉 + 量比过滤，本质是低换手的趋势信号），MC 中位数 -0.03%~-25.64%，仍然不是正。

## 一、数据与方法

| 项 | 值 |
|----|----|
| 数据源 | OKX `/market/history-candles`，USDT 本位永续（`-USDT-SWAP`），无需 key |
| 币种 | BTC / ETH / SOL（与 4H 基线 research/36 同币种，覆盖涨/跌/震荡三 regime） |
| K 线 | 15m，129999 根（2022-12-12 ~ 2026-08-27，约 3.7 年） |
| 字段 | Open/High/Low/Close/**Volume**（close/volume 均 0 缺失） |
| 手续费 | 基准 0.05% 单边；成本敏感性另测 0.1% / 0.2% |
| 回测 | `vbt.Portfolio.from_signals`，long-only，freq=15min |
| 检验 | 与 research/36 完全同口径：Monte Carlo（诚实 walk-forward，250 条路径 × 5 种子）、CPCV（PurgedKFoldCV，45 测试折组合）、参数扰动（250 条随机选参基线） |

**判读标准**（`classify_dist`，与 36 一致）：真 edge = 中位数>0 且 正占比≥60% 且 P25≥-1% 且不右偏；
运气 = 中位数≤0 或 正占比<50%。「选参跑赢随机」= 网格优化选参的 MC 中位数 > 随机选参基线（且为正）。

## 二、四个微观结构信号定义（全部因果、无未来函数、long-only）

| 信号 | 代码名 | 公式 | 参数网格 |
|------|--------|------|---------|
| **放量突破** | `volbrk` | `entry = (close 上穿前 n 根最高价) & (量比>k)`；`exit = close 跌破 exit_ma 均线`。量比 = volume / n 根滚动均量 | n∈{24,48,96}×k∈{1.5,2.5}×exit_ma∈{100} |
| **量价背离** | `voldiv` | `entry = (close 下穿前 n 根最低价=创新低) & (量比>k_up)` 恐慌买底；`exit = (创新高 & 量比<k_dn 缩量乏力) \| 跌破均线` | n∈{24,48,96}×k_up∈{2,3}×k_dn∈{0.5,0.7} |
| **成交量异动** | `volshock` | `entry = (量 z-score>z_thr) & (价 z-score>move_thr)`；量 z=(vol−滚动均量)/滚动量 std，价 z=单根收益/滚动收益 std | vwin∈{48,96}×z_thr∈{2,3}×move_thr∈{1,2} |
| **量能确认** | `volconfirm` | `entry = (SMA 金叉) & (量比>vthr)` 量价齐升；`exit = 死叉` | fast∈{10,20,30}×slow∈{100,200}×vwin∈{48,96} |

## 三、主结果：Monte Carlo（诚实 walk-forward，首要判据）—— 全部 luck

> 中位数 / 正收益占比 / 正种子（5 个种子中位数为正的个数）。

| 策略 | BTC 中位/正占/正种子 | ETH 中位/正占/正种子 | SOL 中位/正占/正种子 |
|------|---------------------|---------------------|---------------------|
| volbrk（放量突破） | **-21.30%** / 15% / 0/5 | -1.64% / 49% / 2/5 | **-13.76%** / 23% / 0/5 |
| voldiv（量价背离） | -13.61% / 12% / 0/5 | **-35.71%** / 10% / 0/5 | **-37.09%** / 14% / 0/5 |
| volshock（成交量异动） | -17.60% / 26% / 0/5 | **-0.13%** / 50% / 3/5 | **-29.60%** / 0% / 0/5 |
| volconfirm（量能确认） | **-0.03%** / 50% / 2/5 | -2.76% / 46% / 2/5 | -25.64% / 31% / 0/5 |

**12/12 全「luck」，0 个「edge」。** 没有任何信号在任何币上达到「中位数正 + 正占比≥50% + 种子稳定」。
最强的 volshock·ETH（-0.13%/50%/3/5）与 volconfirm·BTC（-0.03%/50%/2/5）也只是「贴着零」，不是正。

**「选参跑赢随机」判定（MC 中位 vs 随机选参基线）：**

| 策略·币 | 网格选参 MC | 随机选参 RAND | 选参有无增量 |
|--------|------------|--------------|-------------|
| volbrk·BTC | -21.30% | -21.39% | ≈ 平（都深负） |
| volbrk·ETH | -1.64% | **+2.51%** | ❌ 选参反而更差 |
| volbrk·SOL | -13.76% | -28.21% | 选参「少亏」但都负 |
| voldiv·BTC | -13.61% | -11.86% | ❌ 选参更差 |
| voldiv·ETH | -35.71% | -38.71% | 都深负 |
| voldiv·SOL | -37.09% | -38.61% | 都深负 |
| volshock·BTC | -17.60% | -27.93% | 都负 |
| volshock·ETH | -0.13% | -7.20% | 都≈负 |
| volshock·SOL | -29.60% | -30.30% | ≈ 平 |
| volconfirm·BTC | -0.03% | -5.64% | 选参「少亏」但≈0 |
| volconfirm·ETH | -2.76% | **+3.41%** | ❌ 选参更差 |
| volconfirm·SOL | -25.64% | -26.76% | ≈ 平 |

**结论：网格选参在 12 个组合里无一「跑赢随机且为正」——3 个「选参反而更差」，其余「都负/平」。**
参数选择没有样本外增量价值，反而在若干币上是负价值（把训练段记住的参数带到样本外就是亏）。

## 四、CPCV（过拟合诊断）—— 部分「漂亮」但 gap 巨大，是假 edge

| 策略 | BTC 中位/正占/gap | ETH 中位/正占/gap | SOL 中位/正占/gap |
|------|------------------|------------------|------------------|
| volbrk | +9.34% / 67% / -0.13 | -3.19% / 47% / +0.13 | +14.07% / 58% / +0.31 |
| voldiv | -10.60% / 27% / +0.11 | -14.72% / 36% / -0.31 | -19.96% / 31% / +0.35 |
| volshock | +9.19% / 58% / -0.14 | +0.03% / 51% / +0.25 | -14.38% / 40% / -0.04 |
| volconfirm | +24.81% / 80% / **+1.01** | +5.34% / 60% / +0.79 | -2.56% / 49% / **+2.64** |

CPCV 里 volconfirm·BTC 被判「edge」（中位 +24.81%、正占 80%、P25 +4.96%），但 **IS-OOS gap = +1.01
（样本内收益比样本外高 101 个百分点）**；volconfirm·SOL gap 更高达 +2.64。这是典型假 edge——
CPCV 的 train 含「test 之后」的未来数据（robust.py 文档已注明），换测试窗就归零。
**在诚实 walk-forward 的 MC 上，volconfirm·BTC 只有 -0.03%。CPCV 的「edge」是 gap 巨大的过拟合假象，不可信。**

## 五、成本敏感性（15m 高频的生死线）—— 换手极高，alpha 一加手续费就蒸发

**读法：**

## 六、与 4H 对比：变好还是没变？—— 没变，甚至更差

| 维度 | 4H 量能因子（research/36） | 15m 微观结构（本任务） |
|------|---------------------------|----------------------|
| 最好单因子的 MC 中位 | volsurge·BTC **+0.50%**（53%） | volconfirm·BTC **-0.03%**（50%）、volshock·ETH -0.13%（50%） |
| 融合信号 MC | multifactor·BTC **+9.92%**（68%，5/5 种子正） | 无融合；最好仍是负/零 |
| 典型单因子 MC | volbreak/volsurge -1.4%~-16%（正占比 6%~53%） | volbrk/volshock/voldiv **-13%~-37%**（正占比 0%~50%） |

**对比结论：**
1. **量能因子在 4H 无效（36 号），在 15m 上不仅没救活，反而更糟。** 4H 的 volsurge·BTC 还能贴着
   +0.50%（53%），15m 的对应信号（volshock·BTC）是 -17.60%（26%）；4H 的融合 multifactor·BTC 是
   全系列唯一 5/5 种子正（+9.92%），而 15m 四个微观结构信号里没有一个正。
2. **「微观结构在 15m 才有、4H 被抹掉」这个假设不成立。** 15m 的成交量/量价信号没有独立 alpha，
   反而因为换手高、信号稀疏、追量被反打而更负。
3. **深层机制**：15m 的量能尖峰（放量突破、放量下跌）在币圈是**局部衰竭/见顶**信号，不是动量延续——
   这解释了为什么「追量做多」在 15m 上是系统性负期望（-13%~-37% 的 MC 中位数，比随机还差）。
   唯一靠 SMA 趋势打底的 volconfirm 换手低、抗手续费，但它的「量」那一票只是过滤、不是 alpha 来源，
   本质上还是已知过拟合的趋势信号（sma）在 30/31/36 号反复验证过的「方向对但不可复用」。

## 八、结论（3-5 条）

1. **15m 微观结构信号没有 4H 没有的 alpha。** 12 个「策略×币」组合的诚实 walk-forward MC 中位数
   全部 ≤0、正占比全部 ≤50%、0/5~3/5 种子不稳，无一通过 edge 检验。假设「微观结构信息在 4H 被抹掉、
   15m 还有」被证伪——至少在这套成交量/量价信号上不成立。

2. **「追量做多」在 15m 是系统性负期望，不是正期望。** 放量突破、成交量异动、恐慌买底三类信号
   MC 中位数 -13%~-37%，正占比 0%~26%，比随机选参还差。机制上，15m 的量能尖峰在币圈是局部衰竭/见顶
   而非动量延续，追量=追顶。这本身是个有用的「反信号」观察（量尖峰→不看多），但不是可交易的 long alpha。

3. **成本敏感性是 15m 的死穴。** 全样本最优收益在 0.05% 还能刷出 +46%~+278%，手续费到 0.1% 就大面积
   转负、0.2% 全崩（换手 790~1300 次/3.7 年）。唯一抗手续费的是低换手的 volconfirm（SMA+量过滤），
   但它的 MC 仍是负——「抗手续费」和「有 alpha」是两回事。

4. **与 4H 比是「没变甚至更差」。** 4H 至少还有 multifactor·BTC（+9.92%/68%/5 种子正）这个唯一正信号，
   15m 四个微观结构信号里一个正都没有。量能因子的病灶（无独立 alpha、选参无增量）从 4H 到 15m 没变，
   高频只是把换手和负期望放大了。

5. **框架价值再验证。** 全样本能刷出 volbrk·SOL +277%、volconfirm·SOL +402% 的「漂亮数字」，
   诚实 walk-forward MC 一打就 -13.76%/-25.64%。CPCV 甚至把 volconfirm·BTC 判成「edge」（+24.81%/80%），
   但 gap 高达 +1.01（101pp）。**「看全样本/CPCV 都是假 edge，只有诚实 walk-forward MC 说了真话」——
   这是本轮最值钱的方法论提醒。**

## 九、局限与下一步

- **long-only**：三类「追量做多」信号 MC 深负，反向（追量做空/量尖峰衰竭做空）可能才是真方向。
  下一步值得把 volbrk/volshock 的镜像（放量突破失败→做空、量尖峰→做空）在 15m 上测一测——
  但要先意识到「深负 MC」也可能只是 grid 选参过拟合的产物，不是干净的负 alpha。
- **信号稀疏**：volconfirm 等低换手信号在 130k 根里只有 176~547 次开仓，MC 的 test 窗（15%~30%）
  可能只有几十次交易甚至零交易，分布里大量零值，中位数对「极少数大输」敏感。要做实需更长历史或更多币。
- **手续费只测了三档总收益**：没有测滑点/资金费率（永续特有）。15m 换手这么高，实盘滑点会把
  「贴零」也打成负。
- **下一步候选**（按优先级）：① 量尖峰衰竭做空（volshock 的 mirror，看深负 MC 是否是干净的负 alpha）；
  ② 用真 OI（非 volume 代理，36 号已证两者不相关）重做 15m 微观结构；③ 给 volconfirm 加 regime 过滤，
  只在「趋势 regime」启用量能确认，看能否把 -0.03% 的 BTC 转正。
