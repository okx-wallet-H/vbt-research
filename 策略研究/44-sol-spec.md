## 一句话结论

**这是一个「SOL 专属、多空混合驱动的趋势跟踪 edge」，不是普适做空 alpha。**
全历史（2021-2026，含 2022 熊市）protected Monte Carlo 中位数 **+19.49%**、P25 **-1.00%**、
正收益占比 **73%**、**5/5 种子**，判定 **edge**。但它带三个铁律般的诚实标注：
**(a) 只对 SOL 成立**（BTC/ETH/DOGE 同参数全负）；**(b) 收益大头在多头侧**（做空是有界下行对冲）；
**(c) 保护层在单边阴跌慢熊里会小亏做空盈利**（按波动结构切换保护开关）。

## 一、策略定义（精确公式 + 数据来源）

### 1.1 标的

| 项 | 值 | 来源 |
|----|----|----|
| 标的 | SOL-USDT-SWAP（OKX USDT 本位永续） | research/39/40 |
| K 线 | 4H | research/39/40 全程 4H |
| 手续费 | 0.05% 单边（taker 档位） | research/39/40 同口径 |
| 数据源 | OKX `/market/history-candles`（无需 key） | data.py 已验证 |

### 1.2 信号公式：SMA 快慢线交叉（双向）

```
SMA_fast(t) = mean(close[t-19 .. t])       # 快线，窗口 20
SMA_slow(t) = mean(close[t-49 .. t])       # 慢线，窗口 50

金叉（开多/平空）: SMA_fast 上穿 SMA_slow   = crossed_above
死叉（开空/平多）: SMA_fast 下穿 SMA_slow   = crossed_below
```

- 双向、始终在场、交叉翻转：金叉做多（若持空则同时平空），死叉做空（若持多则同时平多）。
- 做空信号 = 多单信号的镜像（`strategy.full_signals` 的 `short_entries=exits`、`short_exits=entries`）。

**参数来源**：`fast=20 / slow=50` 来自 **research/39**（其在 research/32 的网格
`fast∈{10,20,30}×slow∈{40,50,60}` 上经多币多策略对比 + Monte Carlo 收敛到 20/50，作为固定参数、
零选参）。**不是「我觉得 20/50 好」，是网格+MC 选参的结果。**

### 1.3 做空限损公式（只作用于做空侧，long 侧不动）

| 保护 | 触发条件（公式） | 参数 | 来源 |
|------|----------------|------|------|
| σ 挤压 | 做空期间单根涨幅 `close[i]/close[i-1] − 1 ≥ squeeze_k × std(单根收益, 滚动20)` → 平空 | squeeze_k=**2.5**、窗口 **20** | research/39 §二/§四 |
| 时间止损 | 持仓 ≥ N 根且未盈利（`close[i] ≥ entry`）→ 平空 | N=**20**（4H ≈ 3.3 天） | research/39 §四 |

- `entry` = 死叉当根收盘价（= from_signals 的做空成交价，close-to-close 口径）。
- `std(单根收益, 滚动20)` 用「含当根收益」的滚动 20 根 std（保守口径，避免当根暴涨把 std 抬高导致阈值自我稀释）。
- 触发与参考价都用**收盘价**（不用盘中 high），是**下界**（真实盘中 high 触发只会更好，research/39 §六）。
- **不设固定百分比止损**：research/39 实测固定止损 sl 会跟 SMA 金叉平空「打架」（sl=8% 反而更差，
  MC 中位 +5.50%→+4.51%）。σ挤压+时间止损是「事件型」保护，与金叉互补、不打架。

**参数来源（关键，非拍脑袋）**：
- `squeeze_k=2.5`：research/39 全场唯一「单因子就够 edge」的档位（sqsig=2.5：MC 中位 +9.70%、
  MC P25 +0.15% 转正、正占 75%、5/5 种子）；sqsig=2.0 过紧（3/5 种子）、3.0 也稳（+7.41%）。
- `time_stop=20`：time=20 单因子 edge（MC P25 +3.92% 转正、CPCV P25 抬 +8.1pp）；**time=5 也 edge**
  （+1.32%），说明「砍死仓」这个动作本身稳健、不是某个 N 值过拟合。
- 组合 `sqsig2.5+t20` 是全场最优（MC 中位 +14.33%、P25 +6.05%、正占 83%、5/5 种子）。

## 二、止损价设置（k 的拟合方法 + 数据来源）

> 用户要求：止损价公式的 k 必须「从回测数据拟合」，让止损价公式和已验证的做空限损逻辑**一致**。
> 本规范给两个口径，主口径零拟合（直接 = research/39 参数），ATR 口径经全历史拟合。

### 2.1 主口径（k×σ，零拟合误差，与 σ挤压严格一致）

```
σ_20(t) = std(单根收益, 滚动20)                 # 收益率口径（无量纲）
D       = k × σ_20 × entry = 2.5 × σ_20 × entry
做空止损价 stop_short = entry + D = entry × (1 + 2.5·σ_20)     ← = σ挤压触发价
做多止损价 stop_long  = entry − D = entry × (1 − 2.5·σ_20)     ← 对称风险预算价
```

- **k = 2.5 就是 research/39 的 `squeeze_k`**：σ挤压触发条件 `单根涨幅 ≥ 2.5×σ_20` 等价于
  `做空止损价 = entry×(1+2.5σ_20)`。**零拟合误差** —— 这就是已验证的做空尾部保护本身，不是另造的参数。

### 2.2 等价 ATR 口径（k_ATR = 1.5，全历史拟合）

```
做空止损价 stop_short = entry + k_ATR × ATR14     （ATR14 = Wilder 平滑真实波幅，价格口径 USDT）
做多止损价 stop_long  = entry − k_ATR × ATR14
```

**k_ATR 拟合方法**（本机实跑，脚本可复现）：
对每根 bar 计算「σ挤压触发距离」与 ATR14 的比值，取时间序列分布的代表值：

```
k_ATR_i = 2.5 × σ_20_i × close_i / ATR14_i
k_ATR   = median(k_ATR_i)
```

拟合结果（SOL 4H，`backtest/output/bear_data.pkl` 全历史 12260 根）：

| 拟合区间 | median | mean | P25 | P75 |
|---------|--------|------|-----|-----|
| 全历史 2021-01-22 ~ 2026-08-27 | **1.5111** | 1.5361 | 1.3205 | 1.7155 |
| research/39 窗口（2025-04-14 起） | **1.5342** | 1.5538 | 1.3552 | 1.7220 |

**取整 k_ATR = 1.5**（全历史中位数 1.51，落在 P25~P75 区间内，稳健）。
数值直觉：ATR14 ≈ 1.65×σ_20×close（比值中位数 1.6545），故 `2.5×σ_20×close ≈ 1.5×ATR14`。

> 诚实标注：**做多止损价 k 是对称假设，不是回测 edge**。research/39 的保护只作用于做空侧，
> 做多侧无回测固定止损（实际出场是 SMA 死叉）。做多的 stop_long 只用于**风险反推仓位**（限制单笔敞口），
> 不构成「做多侧已验证的止损」。

### 2.3 实盘止损触发价类型

- 回测用 close 触发（保守下界）；实盘挂 `slTriggerPxType=last`（最后成交价触发，更即时，
  只会比 close 触发更好，research/39 §六已说明）。
- `slOrdPx = -1`（OKX 约定：-1 = 市价止损，触发即市价平仓）。

## 三、仓位公式（双重约束风险反推法，okx-perp 同款）

### 3.1 合约规格（实查 OKX `/api/v5/public/instruments`，2026-08-27，禁止假设）

| 项 | 值 | 含义 |
|----|----|----|
| ctVal | **1** | 每张合约面值 = 1 SOL（ctValCcy=SOL） |
| lotSz | **0.01** | 下单精度（张） |
| minSz | **0.01** | 最小下单量 |
| tickSz | 0.01 | 价格精度 |
| lever（交易所） | **100** | OKX 杠杆上限 |

### 3.2 资金参数（用户拍板 + 公式支撑）

| 参数 | 值 | 说明 |
|------|----|----|
| 本金 P | **500 USDT** | 用户拍板（小仓位实盘验证） |
| 单笔风险 r | **2%** | 单笔最大亏损 = P·r = **10 USDT** |
| 杠杆上限 L_max | **5x** | 用户拍板（策略杠杆上限，远低于交易所 100） |
| 保证金动用比例 M | **0.30** | 只用 30% 本金作保证金，留 70% 缓冲 |

### 3.3 公式

```
D      = |entry − stop| = 2.5 × σ_20 × entry            # 止损距离（USDT/张）

Q_risk = P·r / (D·ctVal)                                # 风险约束：止损距离内最多亏 P·r
Q_lev  = P·M·L_max / (entry·ctVal)                      # 杠杆约束：名义 ≤ P·M·L_max
Q      = floor(min(Q_risk, Q_lev) / lotSz) × lotSz      # 向下取到 lotSz 整数倍（张）
```

**实测样例（2026-08-27，entry=105.25、σ_20=1.8124%）**：

```
D       = 2.5 × 1.8124% × 105.25 = 4.769 USDT
Q_risk  = 500×2% / (4.769×1) = 2.0969
Q_lev   = 500×0.30×5 / (105.25×1) = 7.1259
Q       = floor(2.0969/0.01)×0.01 = 2.09 张（= 2.09 SOL）
名义敞口 = 2.09×105.25 = 219.97 USDT（占本金 44%）
单笔最大亏损 = 2.09 × 4.769 = 9.97 ≈ 10 USDT = 2% 本金 ✓
```

> 读法：小账户下 `Q_risk`（风险约束）先绑定，杠杆约束 `Q_lev` 只是「不许超过 5x 名义」的硬上限。
> 实际隐含杠杆 = 名义/保证金 = 219.97/(500×0.30) = 1.47x，远低于 5x —— 风险反推天然低杠杆。

## 六、小仓位验证方案（提前定退出标准，不拍脑袋）

### 6.1 初始资金与单笔风险

| 项 | 值 | 依据 |
|----|----|----|
| 初始资金 P | 500 USDT | 用户拍板（小仓位，够付手续费/滑点 + 验证最小张数） |
| 单笔风险 r | 2%（=10 USDT） | ① 做空尾部由 σ挤压(2.5σ) 限损，单笔最大单根损失 ≈ D ≈ 4.77 USDT/张，r=2% 让一次 σ挤压尾部最多亏 P·r=10 USDT；② 2% 是趋势跟踪标准风控（2% 规则）；③ P=500 下 10 USDT 单笔损失可承受 |
| 杠杆 L_max / 保证金 M | 5x / 0.30 | 用户拍板（okx-perp 项目已定，有公式支撑） |

### 6.2 验证期时长

**≥ 3 个月（≈540 根 4H）或 ≥ 20 笔完整交易（多空各 ≥10 笔），取先到者。**
依据：research/40 R6 窗口 125 根 ≈ 2.5 个月；一个完整多空翻转周期 + 至少一次 σ挤压/时间止损保护触发
需要数月；20 笔交易才能让趋势跟踪（胜率 ~30-40%）的统计有意义。

### 6.3 有效判定（4 条全过）

1. **正收益且跑赢买持**：验证期累计净收益 > 0 且 ≥ SOL 买持（benchmark）。
2. **回撤受控**：最大回撤 ≤ 15%。
3. **保护生效**：做空侧 σ挤压/时间止损至少触发 ≥ 1 次（证明保护层实际在起作用）。
4. **样本外一致**：验证期收益落在 research/39/40 MC 分布的 P25~P75 区间（≈ -1% ~ +14.77%），而非极端尾部。

### 6.4 无效判定（任一触发即停）

1. **累计回撤 ≤ -15%**：依据 research/40 全历史 protected MC P25 = -1.00%、分层最差（2022 熊）P25 = -14.86%。
   -15% 是「历史最差 regime 的典型下尾」，跌破 = 进入历史未见的更差行情 → 停。
2. **连续 10 笔交易全亏**：趋势跟踪胜率 ~30-40%（research/39 时间止损后 short 胜率 30.3%），
   连续 10 亏的概率极低，出现即策略失效签名。
3. **进入「单边阴跌慢熊」且保护持续负贡献**（research/40 标注 c）：σ挤压事件频率≈0 且持续，
   按 §7 切 --no-protection；若切换后仍连续亏损，停。
4. **实盘净收益 < 回测净收益的 30%**：手续费/滑点/资金费率吃掉大部分 alpha（research/39 §六 已提示
   资金费率是永续特有、未在回测内），说明成本结构不支撑实盘。

## 七、硬风控规则（脚本内置，`backtest/sol_strategy.py`）

| # | 风控 | 规则 | 依据/实现 |
|---|------|------|----------|
| ① | **止损必挂** | 每笔开仓单必须带 `slTriggerPx`/`slOrdPx=-1`/`slTriggerPxType=last`；缺止损拦截 | 脚本 `build_order` 强制注入；`risk_guard` 校验缺止损即拦截 |
| ② | **单策略单仓位** | 不同时多笔持仓；状态机保证 always-in-market 单一持仓（多/空/flat 三者取一） | 状态机前向扫描，输出「翻转/开仓/平仓」单笔指令 |
| ③ | **日亏损熔断** | 当日累计风险预算 ≥ **3 × 单笔风险（=30 USDT = 6% 本金）** → 当日停 | 依据：r=2%，连续 3 笔止损 = 6% 本金回撤，作为小仓位单日硬止损线；脚本用「预估风险」口径（每次开仓累加 P·r=10 USDT，保守上界），持久化 `sol_strategy_state.json` |
| ④ | **异常自动停机** | 数据/信号计算异常 → 返回非零、禁止下单，不盲目重试 | `main` 里 try/except 包裹数据+信号计算 |
| ⑤ | **第一单 dry-run** | 默认 `--dry-run` 只输出完整参数（含止损），用户过目确认后才 `--live` 放行 | CLI 默认 dry-run；`--live` 才累加风险预算并放行 |

> **资金红线**：脚本**不持有 OKX 私钥、不直接发下单 HTTP 请求**。它产出「已放行的完整下单指令 JSON」
> （含止损），真实下单由 Claude 主会话调用 okx-trade-mcp `swap_place_order` 执行，且必须先过 dry-run。

### 7.1 保护开关切换（标注 c 的落地）

脚本内置「波动结构诊断」：统计近 120 根里「单根涨幅 ≥ 2.5σ」的占比（σ挤压事件频率），
**只输出提示、不自动切换**（自动切换是无回测的新规则，违反铁律）：

- 频率 > 0 → 波动结构偏「早盘暴涨」（2025-2026），保护 **ON**（默认）。
- 频率 ≈ 0 且持续 → 波动结构偏「单边阴跌」（2022 式慢熊），按 research/40 标注(c) **手动** `--no-protection`。

> `--live` 的语义是「**预留制**」：脚本在硬风控放行后把本笔单笔风险 P·r 累加进当日风险预算（视为「即将执行」），

> 这个「脚本生成 → 主会话执行」的分离是资金红线：脚本不持私钥、不直接发下单请求。
