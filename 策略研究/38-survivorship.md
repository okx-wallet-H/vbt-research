# 38 — 幸存者偏差坐实：横截面动量 alpha 还剩多少

> 追问 research/34 留下的头号隐患：「60 币池是今天还活着的币」。本报告用**点-in-time 数据**精确量化
> 幸存者偏差到底吃掉了多少 alpha——不是"大概评估"，而是三档币池实跑对比。
>
> 全部数字来自 `backtest/output/survivorship_results.json`，脚本 `backtest/survivorship.py`（引擎）、
> `backtest/fetch_pt_universe.py`（点-in-time 取数）、`backtest/fetch_delisted.py`（下架币补回），
> 全部真实 OKX + Binance 数据实跑，可复现。

---

## 一句话结论

**幸存者偏差是致命的——它吃掉了横截面动量几乎全部的 alpha。**

- research/34 的 Monte Carlo 中位数 **+5.78%（正占比 74.8%，判 edge）**，坐实后（点-in-time 完整币池 + 下架币补回）
  掉到 **+0.17%（正占比 50.4%，判 inconclusive）**。
- **幸存者偏差吃掉的 alpha = +5.61pp**（MC 口径，A档 − C档），固定参数口径 +6.29pp。alpha 从"显著正"直接归零。
- **但偏差的方向与 research/34 的猜想相反**：不是"下架币缺失高估了短腿"，而是"**今日流动性前 60 的 look-ahead 选样**"
  才是虚高的主因。下架币是「可做空的输家」，把它们补回反而**帮**策略（+6.23pp），因为它们正是短腿想空的标的。
- **坐实后的判定**：横截面动量按 research/34 的口径**不值得做**——它的 edge 是「今日前 60 大币」这一回顾性选样的产物，
  一旦换成现实可交易的币池（150 币点-in-time），Monte Carlo 中位数转负（-6.06%）。

## 一、数据与方法：点-in-time 币池重建

### 1.1 三个关键数据事实（每个都先验证过，见 §五数据来源）

**事实①：当前 60 币池其实没有「未来币」偏差。** research/34 的 60 币池（`xsec_big.pkl`）里全部 60 个币的
`listTime` 都早于回测起点 2025-04-14（已验证：60/60 `listTime < 2025-04-14`，最晚的是 GPS 2025-03-04）。
任务假设的「2025 年 4 月的时点却包含了 2025 年 10 月才上市的币」**不成立**——`fetch_big_pool.py` 在取数时已经用
`has_full_history`（= listTime < 2025-04-14）过滤过了。所以「未来币」这一块偏差 = 0，需要澄清。

**事实②：OKX 已清除下架币的历史数据。** 对 2025~2026 下架的 36 个 USDT 永续逐个请求
`/market/history-candles`，**全部返回 code 51001「Instrument ID doesn't exist」**（已验证 36/36）。
即 OKX 在下架后**删除了历史 K 线**，无法从 OKX 侧补回下架币数据（对比：老牌下架币 LUNA-USDT-SWAP 仍返回 5 根，
属特例）。下架币数据只能走第三方。

**事实③：回测窗口内 OKX 下架了 36 个 USDT 永续**（2025-06-05 ~ 2026-01-24，跨 8 批，见 §五）。
其中 **14 个仍在 Binance 现货可查到 4H 数据**（MOVR/GUN/WAXP/DGB/JOE/CVC/BNT/NEWT/CETUS/SOLV/TURTLE/CATI/TREE/COOKIE），
用 Binance 现货价作 OKX 永续的价格代理；其余 22 个（J/SWEAT/PUFFER/SUNDOG/X/BSV/BR/SWELL/ZEREBRO/NEIROETH/ALCH/DOG/
UXLINK/AI16Z/CTC/ZENT/PRCL/GOAT/SONIC/DEGEN/JCT/BLUAI）Binance 也已下架或未上，数据不可得 → 记为**残留下限**。

### 1.2 点-in-time 币池构造（公式）

对每个回测时点 t，真实可交易币池 = `{ 币 i : listTime_i ≤ t 且 t < delistTime_i }`。

```
币池_t  = { 上市已发生 } ∩ { 尚未下架 }
        = { i : listTime_i ≤ t } ∩ { i : t < delistTime_i }
```

- **上市维**：`listTime` 来自 OKX `/public/instruments`（459 个 SWAP，其中加密 instCategory=1 共 290 个，
  175 个 pre-cutoff、115 个 post-cutoff，已验证）。币 i 在 `listTime_i` 之前列值为 NaN，不参与该时点的截面排名。
- **下架维**：`delistTime_i` 来自 OKX 官方 help 页 + 第三方公告；币 i 在下架日（含）之后置 NaN（不能再交易）。

### 1.3 三档币池定义

| 档 | 币池 | 说明 |
|----|------|------|
| **A（当前，含偏差）** | 60 币，`xsec_big.pkl` | research/34 原样：今日流动性前 60 且 listTime<2025-04-14 的加密永续 |
| **B（点-in-time 上市过滤）** | 150 币，`xsec_pt.pkl` | 上市维点-in-time：top-120 pre-cutoff + top-30 post-cutoff（按今日成交额排序），未上市期 NaN，随上市动态扩充 |
| **C（点-in-time + 下架币补回）** | 164 币，B + 14 下架币 | 上市维 + 下架维都点-in-time：14 个下架币（Binance 现货代理）在 `listTime~delistTime` 区间参与，下架日后置 NaN |

> 口径说明：B/C 档仍是「按**今日**成交额排序取 top-N」，不是严格的逐时点成交额选样——这是本报告**残留的 look-ahead**
> （见 §六），但它比 A 档的「今日前 60」要松得多，足以让「选样偏差」暴露出来。方向性结论不受影响。

信号/权重/组合/Monte Carlo/CPCV 全部复用 `backtest/xsec.py`（引擎已升级为 NaN-aware，见 §四脚注），
参数网格、再平衡（周频 42 根）、手续费（0.05% 单边）与 research/34 完全一致，唯一变量是**币池**。

## 二、三档对比（核心）

### 2.1 主结果（Monte Carlo OOS 收益中位数，与 research/34 同口径）

| 档 | 币池规模 | 全样本最优(lb,k) | 全样本净收益 | **MC 中位数** | MC 正占比 | 固定参数 MC | 判定 |
|----|---------|-----------------|-------------|--------------|----------|------------|------|
| **A 当前60币** | 60 | (24,10) | +33.4% | **+5.78%** | **74.8%** | +6.83% | ✅ edge |
| **B 点-in-time** | 150 | (168,10) | +56.2% | **−6.06%** | **33.6%** | +0.80% | ❌ luck |
| **C +下架币补回** | 164 | (168,10) | +65.5% | **+0.17%** | **50.4%** | +0.54% | ⚠️ inconclusive |

**读出来的四件事**：

1. **币池一扩张，alpha 就崩**：60→150 币，MC 中位数从 +5.78% 崩到 −6.06%（正占比 74.8%→33.6%）。research/34
   的 edge **几乎全部来自「今日流动性前 60」这个回顾性选样**——这是一个 look-ahead 的「赢家俱乐部」：2026 年还
   排进前 60 的币，本身就是在 2025 熊市里活下来且还火的币。
2. **补回下架币反而帮了一点**：B→C（+14 个下架币）把 MC 中位数从 −6.06% 拉回 +0.17%。下架币是 -68%~-94% 的
   极端输家（§3.2），正是短腿想空的对象，补回它们让短腿的「可空标的」变多了。
3. **最优回看期翻转**：A 档最优 lb=24（4 天），B/C 档最优 lb=168（1 个月）。research/34 的「币圈动量在几天尺度」
   这个结论**只在今日前 60 大币里成立**，换到 150 币现实池就翻转到月尺度——说明这个「短周期动量」本身是选样敏感的。
4. **全样本高、MC 负 = 典型过拟合**：B 档全样本最优 +56.2%，但 MC 中位 −6.06%——选参在训练段刷出高收益、样本外
   打回原形。这正是 research/31 单币时序的那种过拟合签名，现在横截面动量在现实币池里也复现了。

### 2.2 幸存者偏差量化（公式 + 数字）

按任务公式，**偏差 = A档 alpha − C档 alpha**（alpha 用 MC 中位数，与 research/34 同口径）：

```
幸存者偏差(总)   = MC中位数(A) − MC中位数(C)
                 = +5.78% − (+0.17%) = +5.61pp   ← 幸存者偏差吃掉的 alpha

拆成两个分量：
选样偏差(上市/规模) = MC中位数(A) − MC中位数(B)
                 = +5.78% − (−6.06%) = +11.84pp   ← 主凶：60 vs 150 的选样
下架偏差(纯)      = MC中位数(B) − MC中位数(C)
                 = −6.06% − (+0.17%) = −6.23pp   ← 负值 = 下架币缺失反而「低估」了短腿
```

| 偏差项 | MC 口径 | 固定参数口径 | 含义 |
|--------|---------|-------------|------|
| **幸存者偏差(总) = A − C** | **+5.61pp** | **+6.29pp** | 今日60币池把 alpha 高估了 ~6pp |
| 选样偏差 = A − B | +11.84pp | +6.03pp | 主凶：60 vs 150 的 look-ahead 选样 |
| 下架偏差 = B − C | −6.23pp | +0.26pp | 下架币缺失**低估**短腿（方向与猜想相反） |

**公式验证**：`+5.61% = +11.84% + (−6.23%)` ✓（A−C = (A−B)+(B−C)）。

**这是本报告最重要的机制发现——偏差方向与任务假设相反**：

- 任务假设（research/34 §六）：「下架币不在池里 → 短腿做空输家被高估 → 收益虚高」。
- 实测：**下架币缺失是「低估」短腿**，不是高估。原因：横截面策略**做空**输家，下架币是最极端的输家
  （buy-hold −68%~−94%），把它们补回池里让短腿多了一批「该被空」的标的，策略反而更好（B→C +6.23pp）。
- 真正让 research/34 虚高的不是下架偏差，是**选样偏差（+11.84pp）**：60 币池是「2026 年还排前 60」的回顾性选样，
  这些币本身就是「活下来且还火」的赢家，用它们回测天然高估「选强」的命中率。

### 2.3 腿分解（lb=24 k=10 周频，全样本净收益）

| 腿 | A(60币) | B(150币) | C(164币) |
|----|---------|----------|----------|
| 长腿（多 top-K） | +12.1% | −34.3% | −24.9% |
| 短腿（空 bottom-K） | −21.7% | +9.1% | −13.4% |
| 价差（spread, gross=2） | +65.7% | +36.5% | −2.4% |
| 等权市场 | −32.9% | −36.6% | −41.6% |

- **长腿从 +12.1% 翻到 −34.3%**：B 档的 150 币里多了大量小市值币，长腿（做多动量强者）在熊市里做多小币 = 灾难。
  research/34 里「长腿单独 +12%」是建立在前 60 大币「强者恒强」上的，小币没有这个结构。
- **短腿方向翻转**：A 档短腿 −21.7%（大币超跌反弹，做空被打脸），B 档短腿 +9.1%（小币持续阴跌，做空赚钱）。
  这解释了为什么「补回下架币（极端输家）帮了短腿」。
- **价差在 C 档归零（−2.4%）**：把上市 + 下架两维都点-in-time 后，「多强空弱」的截面价差 alpha 直接消失。

## 三、坐实后的判定

### 判定：幸存者偏差是致命的，横截面动量（research/34 口径）的 alpha 归零

| 问题 | 答案（数字） |
|------|-------------|
| 幸存者偏差吃了多少 alpha | **+5.61pp（MC）/+6.29pp（固定参数）** |
| 坐实前 MC 中位数 | +5.78%（74.8% 正，edge） |
| 坐实后 MC 中位数 | **+0.17%（50.4% 正，inconclusive）** |
| 坐实后还值得做吗 | **不值得**（按 research/34 的口径） |

**具体判定逻辑**：

1. **alpha 归零**：点-in-time 完整币池（C 档）MC 中位数 +0.17%，正占比 50.4%，P25 −6.95%——这正是
   `classify_dist` 的「inconclusive」（介于 edge 和 luck 之间，中位数≈0）。research/34 的 +5.78%/74.8%/5种子全正
   在现实币池里**不成立**。
2. **主因不是下架，是选样**：+11.84pp 的选样偏差（60 vs 150）远大于下架偏差（−6.23pp，且方向相反）。
   「今日流动性前 60」是一个无法在 2025 年提前知道的 look-ahead 集合，用它回测是**回顾性选赢家**。
3. **小币没有截面动量**：B/C 档最优回看期翻转到 lb=168（月尺度）、长腿转负、全样本高但 MC 负——这套签名说明
   横截面动量只在**大市值高流动性币**里有短暂的结构，在 150 币的完整现实池里不存在稳定 alpha。

### 还值不值得做——一个诚实的保留

如果还想抢救，唯一说得通的路径是：**用「点-in-time 流动性前 N（N 小，如 30~60）」重建币池**（即每个时点按
当时的成交量/成交额选前 60，而非今日的前 60）。本报告的 B/C 档是「今日成交额排序」的近似，仍残留 look-ahead；
真正的点-in-time 流动性选样需要历史成交量数据（`history-candles` 的 vol 字段可取，但需逐币回拉并做逐时点排序）。
这是**下一个任务**，不是本报告能下结论的——但它能否救回 alpha，取决于「大币的截面动量」在严格点-in-time 流动性
选样下是否还成立。就本报告的数据而言，**按 research/34 的现有口径，答案是否定的**。

## 四、方法脚注（复现口径）

- `backtest/xsec.py` 的 `cross_sectional_weights` 已升级为 **NaN-aware**：截面排名用「每行实际非 NaN 币数」
  （`n_active = mom.notna().sum(axis=1)`）代替固定的 `ncols`，top/bottom-K 按每行实际可交易币数选取。这样动态币池
  （未上市=NaN）的排名才正确。**已验证该改动不改变 60 币池结果**（lb=24 k=10 仍 +33.43%，与 research/34 一致）。
- 三档共用同一参考索引（A 档 3000 根 4H，2025-04-14 08:00 ~ 2026-08-27 04:00），B/C 档 reindex 到该索引，
  未上市/已下架期填 NaN。B 档取数窗口与 A 档有 1 根 4H 的边界偏移（B 起点 12:00 vs A 08:00），影响可忽略（3000 根中 1 根）。
- 下架币用 Binance 现货 4H 作 OKX 永续代理：现货价≠永续价（无资金费率、无杠杆），但对「动量排名 + 方向」的
  近似足够；且只用到下架日为止（下架后置 NaN）。

## 六、残留局限（不掩盖）

1. **C 档是下限**：36 个下架币只补回 14 个（Binance 可得），另 22 个数据不可得。但这 22 个同为极端输家，补回只会
   进一步抬高 C 档（帮短腿），使「幸存者偏差(总)」**更小**——所以 +5.61pp 是偏差的**上限**，结论「alpha 归零」不变。
2. **B/C 档的「今日成交额排序」仍是 look-ahead**：真正的逐时点流动性选样需要历史成交量，本报告未做（见 §三保留）。
3. **Binance 现货 ≠ OKX 永续**：下架币的动量/收益用现货近似，方向性结论稳健，精确数字有误差。
4. **窗口仍是 16 个月**：未覆盖 2022 熊市/2024 牛市，不排除「大币截面动量」在其他 regime 有效的可能（但那是另一
   个研究问题，与本报告的「幸存者偏差坐实」无关）。
